# CiteLab — Learn APA 7 by Doing

CiteLab is a browser-based citation laboratory for Egyptian STEM students. It teaches APA 7th edition referencing through interactive investigation, construction, inspection, and mastery exercises rather than static examples.

## Features

- **Lab console** with an evidence-chain workflow: Source → Evidence → Claim → Citation → Reference → Understanding.
- **Learn** section with structured lessons on APA 7 rules.
- **Train** section with evidence packets, reference construction, accuracy drills, and in-text application.
- **Build** section for constructing references from raw evidence.
- **Inspect** section for forensic analysis of incorrect citations and reconstruction.
- **Research desk** with a source taxonomy explorer (journal vs. book comparison).
- **Mastery** section with a skill map, dossier, and progress ledger.
- Light/dark ("Night Study Lab") theme variants.
- Responsive layout for desktop, tablet, and mobile.

## Technology stack

- **Frontend:** HTML, CSS, vanilla JavaScript (no build step).
- **Assets:** screenshots under `screenshots/`.

## Running locally

Open `index.html` in a modern browser. No installation or build is required.

## Limitations

- Client-side only; no accounts, persistence, or backend.
- Content is tuned for Egyptian STEM students and APA 7.
